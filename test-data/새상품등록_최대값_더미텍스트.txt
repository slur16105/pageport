PAGEPORT 새 상품 등록 최대값 테스트용 더미 데이터
==================================================

[사용 방법]
1. 관리자 화면에서 새 상품 등록을 엽니다.
2. 아래 항목별 값을 복사해서 같은 이름의 입력칸에 붙여 넣습니다.
3. 반드시 판매 상태를 "작성 중"으로 두고 저장 테스트를 합니다.
4. 극단적인 판매가와 쪽수는 실제 결제용 값이 아닙니다. 결제 테스트에는 사용하지 마세요.


1) 상품명 — 최대 80자
--------------------------------------------------
한 장으로 완성하는 초대형 프로젝트 일정 업무 목표 예산 회의 고객 관리 통합 플래너 테스트 에디션 한글 영문 숫자 2026 특수문자 포함 PDF 디지털 문서 최대 길이 표시 줄바꿈 말줄임표 레이아웃 검사용 상품


2) 판매자명 — 최대 50자
--------------------------------------------------
페이지포트 공식 테스트 판매자 주식회사 디지털문서연구소 기업사업자 최대길이 화면검증 전용상점


3) 카테고리 — 선택 항목
--------------------------------------------------
업무·생산성

직접 글자를 입력하는 칸이 아닙니다. 준비된 6개 카테고리를 한 번씩 선택해 확인합니다.


4) 판매가 — 최대 1,000,000원
--------------------------------------------------
1000000

주의: 화면과 저장 한계 확인용 값입니다. 실제 토스 시험 결제를 시도하지 마세요.


5) PDF 쪽수 — 최대 10,000쪽
--------------------------------------------------
10000

주의: 저장·화면 한계 확인용 값입니다. 실제 PDF 쪽수와 일치하는 값으로 운영 상품을 등록해야 합니다.


6) 표지 글자 — 현재 허용된 정확한 최대 12자
--------------------------------------------------
가나다라마바사아자차카타


7) 표지 색상
--------------------------------------------------
각 색상을 한 번씩 바꾸어 확인: 민트 / 노랑 / 파랑 / 분홍 / 보라 / 주황 / 연두 / 코랄


8) 한 줄 소개 — 최대 160자
--------------------------------------------------
목표와 일정, 우선순위, 회의 기록, 고객 요청, 예산과 회고를 한 문서에서 관리하도록 구성한 초대형 통합 플래너입니다. 긴 상품 소개가 목록 카드와 상세 화면, 모바일 3열 화면에서 알맞게 줄어들고 말줄임표가 적용되는지 확인하기 위한 테스트 문장입니다. 한글과 English, 숫자 1234567890, 괄호와 쉼표·가운뎃점 같은 문자가 함께 표시되는지도 확인합니다.


9) 상세 설명 — 최대 2,000자
--------------------------------------------------
이 상품은 PAGEPORT 새 상품 등록 기능의 최대 길이와 화면 표시 상태를 확인하기 위한 테스트용 PDF 상품입니다.

첫 번째 문단에서는 긴 설명을 입력했을 때 관리자 화면에서 내용이 잘리지 않는지 확인합니다. 저장한 뒤 상품 상세 페이지에서 문단과 줄바꿈이 자연스럽게 표시되는지, 모바일 화면에서 글자가 화면 밖으로 나가지 않는지, 긴 단어와 숫자가 레이아웃을 밀어내지 않는지 함께 확인합니다.

두 번째 문단에서는 구매자가 상품의 용도를 쉽게 이해할 수 있는지 확인합니다. 목표 설정, 주간 일정, 오늘 할 일, 회의 기록, 고객 요청, 예산 관리, 완료 항목, 회고 질문을 한 PDF 안에서 확인할 수 있다는 가상의 설명을 사용합니다.

세 번째 문단은 특수문자 표시 확인용입니다. 괄호( ), 대괄호[ ], 더하기+, 빼기-, 슬래시/, 앰퍼샌드&, 따옴표“ ”, 숫자 0123456789, 영문 ABCDEFGHIJKLMNOPQRSTUVWXYZ가 정상적으로 보이는지 확인하세요.

마지막으로 상품을 "작성 중"으로 저장하고 상품 목록, 수정 화면, 상세 화면의 문장이 모두 유지되는지 확인합니다. 이 데이터는 화면과 저장 기능을 시험하기 위한 것이므로 실제 판매 상태로 공개하지 않습니다.

11) PDF 파일
--------------------------------------------------
허용 형식: PDF만 가능
허용 용량: 25MB 이하
파일명 제한: 서버 기준 최대 200자

텍스트 파일은 PDF 입력칸에 올릴 수 없습니다. 별도의 테스트 PDF를 선택해야 합니다.
정확한 최대 용량 테스트는 25MB 이하 PDF로 저장 성공을 확인한 다음, 25MB를 초과한 PDF가 거절되는지 확인하면 됩니다.


12) 판매 상태
--------------------------------------------------
작성 중


[현재 입력 제한]
- 상품명: 80자
- 판매자명: 50자
- 카테고리: 준비된 목록에서 선택
- 한 줄 소개: 160자
- 상세 설명: 2,000자
- 상품 구성: 최대 20개, 한 항목당 100자
- 판매가: 100원 이상 1,000,000원 이하
- PDF 쪽수: 1쪽 이상 10,000쪽 이하
- PDF 파일: 25MB 이하

화면은 각 입력칸 아래에 현재 글자 수와 최대값을 표시합니다. 정확한 경계값 저장 여부는 자동검사에서도 별도로 확인합니다.

[테스트 완료 후 확인할 것]
- 저장 버튼 아래에 성공 또는 오류 안내가 보이는가
- 상품 목록에서 긴 상품명과 가격 때문에 화면이 깨지지 않는가
- 상품 수정 화면을 다시 열었을 때 입력한 내용이 유지되는가
- 모바일에서 글자가 겹치거나 화면 밖으로 나가지 않는가
- 작성 중 상품이 구매자용 상품 목록에는 공개되지 않는가
